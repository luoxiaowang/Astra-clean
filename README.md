# Astra

中文原生 macOS 清理与状态工具。使用 SwiftUI / AppKit 独立实现，无遥测，不依赖原 Mole 程序运行。

## 启动

双击 `dist/Astra.app`。也可以运行：

```sh
open dist/Astra.app
```

当前产物针对本机 Apple Silicon 构建，最低 macOS 14，采用本机 ad-hoc 签名，未做 Apple 公证。可以自行将应用拖入“应用程序”；不要在应用运行中覆盖重建。

## 功能

| 模块 | 已实现 |
| --- | --- |
| 清理 | 扫描用户缓存、日志和下载目录顶层 dmg/pkg/iso；筛选、逐项选择、明细确认、移入废纸篓、逐项结果 |
| AI 工具缓存 | Claude / ChatGPT / Codex / Cursor / OpenCode 缓存；Codex 压缩记录、Claude 会话与 transcripts、Cursor 文件历史；OpenCode 会话只读预览 |
| 软件 | 本机应用列表、版本、名称搜索、按需体积统计、按体积排序、卸载及精确 bundle ID 关联候选 |
| 更新 | 用户触发的 Homebrew cask 更新查询和升级命令提示 |
| 启动项 | 可读取 LaunchAgents / LaunchDaemons 清单与目标路径检查；打开系统登录项设置 |
| 分析 | 木星动画、目录选择、比例矩形树图、面包屑、下钻/返回/刷新、取消、Finder 定位 |
| 优化 | Quick Look 缓存重建、预览插件重新加载、后台服务路径诊断 |
| 状态 | 八卡片、太阳动画、CPU 分核/GPU/内存/网络趋势、电池健康、只读风扇转速、进程搜索/排序/详情 |

AI 工具候选默认不勾选；日常清理扫描会推荐部分缓存项目。执行前复核路径和递归元数据指纹，拒绝符号链接路径、已变化/未完整读取项目、系统目录、运行中应用及其卸载关联数据。失败不会退化成永久删除。已移除项目可以从访达废纸篓恢复。

## 构建与测试

需要 Command Line Tools 和 Swift 5.10+，无需完整 Xcode、npm 或第三方 Swift 包。

```sh
cd Astra
swift run AstraCoreTests
./scripts/build-app.sh
```

本机 CLT 不提供 XCTest，因此测试是独立 Swift 可执行程序。失败返回非零退出码。测试创建自有临时夹具，废纸篓测试将夹具移入废纸篓后恢复，不删除用户文件。

`Sources/AstraCore` 为扫描、安全操作、应用枚举、指标和命令服务；`Sources/Astra` 为 SwiftUI 界面及异步状态；`scripts` 为打包和原创矢量图标生成脚本。

## 已知边界

- 这是第一版同类工具，不是 Mole 的完整功能复刻。暂不包含管理员任务、系统数据库修复、OpenCode 数据库会话删除、worktree/模型清理、风扇控制、全来源自动升级。
- Homebrew 查询基于本地元数据，可能滞后；本工具不自动执行 brew update 或升级。
- 文件统计为逻辑大小，硬链接在一次扫描内去重，APFS 克隆/压缩不会精确映射到物理可释放空间。结果不能解释为“必定释放的空间”。
- 单次扫描最多 300,000 个节点、128 层，达到上限明确报错；最大文件列表只保留 50 项。
- 路径权限错误明确展示；没有读取到的内容不会算作“成功清理”。没有替用户授予完全磁盘访问权限。
- 文件校验与 macOS 路径式废纸篓调用不是原子事务，无法保证对抗恶意进程在极短时间内替换文件；执行前请停止会写入所选目录的应用。
- 网络计数来自 en* 物理接口，排除虚拟隧道，首次采样及计数器重置显示采样中。内存口径为活跃、wired、压缩页之和，可能与活动监视器不一致。
- 文件和应用体积计算遇到权限不足显示未统计/错误，不伪造为零。启动项清单不是当前进程运行清单。

## 界面与资源

清理使用地球和月球，优化使用水星，分析使用木星，状态使用太阳；使用 SceneKit 渲染。纹理来源与署名见 [素材署名](Sources/Astra/Resources/素材署名.md)。
