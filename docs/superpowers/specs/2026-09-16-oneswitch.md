# OneSwitch 首版设计

用户已确认功能和 Tauri 2 + Vue 3 + TypeScript + Rust 方案，并授权开始实施。

- macOS 13+ 菜单栏应用，中文界面，浅灰底、蓝色开关、清晰状态。
- 常亮模式阻止闲置屏幕休眠及闲置系统休眠，不承诺合盖、手动睡眠和聊天在线状态。
- 30 分钟、1 小时、2 小时、手动关闭；启动默认关闭。切换时长从当前时刻重新计时。
- Rust 为状态唯一来源，保存电源断言和绝对到期时间；面板隐藏不影响定时关闭。
- 原生菜单提供打开和退出，面板失焦隐藏；应用退出释放断言。
- 登录启动可选，使用官方 autostart 插件；默认不开启。
- 通过直接 IOKit FFI 实现，不修改全局电源配置，不需要模拟鼠标键盘。
- 不自动 git commit，不更改其他项目。
